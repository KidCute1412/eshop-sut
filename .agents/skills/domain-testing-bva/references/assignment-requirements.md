# HW02 Assignment Requirements Relevant to This Skill

Source: `2026.HW02.Domain Testing_En.pdf`. This working summary does not replace the official PDF.

## Feature Selection

Each student selects four features, one from each official pool A, B, C, and D. Ask for the student's selected feature and pool, record both, and warn if the supplied selection appears to violate this rule. Never select automatically or assume another group member's allocation.

## Required Work

- Apply functional black-box Domain Testing and BVA to requirements, specifications, domains, and observable behaviour.
- Explain the complete process used to derive every test case.
- Manually review and correct AI output; broader high-quality coverage and real findings improve assessment.
- Demonstrate end-to-end skill use on one complete feature. Skills are normally individual work; video narration may use voice-over or captions.
- Make frequent Git commits demonstrating the work.

## Integrity and Submission

Never fabricate execution, status, bugs, screenshots, evidence, or GitHub Issue links. Bug reporting requires an observable reproduced failure against a documented expected result. Preserve AI prompts and outputs, human review/corrections, gap analysis, reports, real evidence, commit history, and required demo/submission materials.
