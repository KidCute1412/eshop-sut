# HW02 Assignment Requirements Relevant to This Skill

Source: `2026.HW02.Domain Testing_En.pdf`, extracted from the project root. This is a concise working summary, not a replacement for the official PDF.

## Feature Selection

Each student must select four features, one from each pool:

- Pool A: Authentication, Categories, and Products.
- Pool B: Shopping Cart and Checkout.
- Pool C: Web Admin.
- Pool D: Mobile App.

Known allocation inconsistency for this project: the current allocation is FR-01, FR-02, FR-07, and FR-17. It contains two Pool A features and no Pool D feature. Record this inconsistency; do not invent a Pool D feature.

## Required Testing Work

For each selected feature:

1. Apply Domain Testing with AI support.
2. Apply Boundary Value Analysis with AI support.
3. Provide a detailed step-by-step explanation of how each technique was applied.
4. Add tests where needed for thorough coverage.
5. Review all AI-generated output manually.

## AI Gap Analysis

Report any missed test cases or missed bugs. Explain the likely reason: prompt quality, AI limitation, missing repository evidence, technique complexity, or human correction.

## Human Responsibility

AI use is allowed, but raw AI output is not acceptable as final work. The student remains responsible for correctness and must review, correct, and refine the results.

## Bug Reporting

Discovered bugs must be recorded in the Markdown report and on the group GitHub Issues page. Bug issues must include screenshots. This skill must never fabricate bugs, screenshots, execution evidence, or issue links.

## Agent Skill and Demo

Students are encouraged to build reusable Agent Skills for Domain Testing and BVA. Submit the skills and YouTube demonstration links showing end-to-end use on a complete feature.

## AI Audit

The AI Audit Report is mandatory. For each AI interaction, record:

- AI tool name.
- Date and time.
- Prompt.
- AI output.

If no AI was used, explicitly declare that. If AI was used, declare the tasks supported by AI.

## AI Critique

Write a mandatory 200-300 word critique describing what AI got wrong, biased, or incomplete; why it failed; and what principle was learned about collaborating with AI.

## Git Commits

Create a new Git commit for each step of the testing procedure of each feature. Provide the commit log in a text-based file.

## Required Submission Materials

The zip submission must include:

- Main report in Markdown and PDF, including Domain Testing and BVA reports.
- Bug report with screenshots of GitHub Issues.
- AI critique and AI Audit Report in Markdown and PDF.
- Git commit log text file.
- README with self-assessment table and test summary report.
- Demo videos.
- Any other supporting materials.

## Test Summary

The README/test summary must include:

- Number of features.
- Number of test cases designed, executed, passed, failed, and not yet executed.
- Number of bugs.
- Demo video links.
