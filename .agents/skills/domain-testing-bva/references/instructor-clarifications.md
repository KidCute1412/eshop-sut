# Instructor Clarifications

1. Domain Testing and BVA are functional black-box techniques based on requirements, specifications, input/output domains, and observable behaviour.
2. Application implementation source, internal architecture, database constraints, and implementation tests must not supply the oracle or expected results.
3. Reports must explain the complete derivation of every case, not merely summarize it.
4. Comprehensive, high-quality cases, real execution evidence, and confirmed bugs improve assessment.
5. Demonstrate work through frequent Git commits.
6. Agent Skills are normally individual work and must be demonstrated end-to-end on one complete feature.
7. A skill video may use voice-over or captions.
8. Never fabricate Pass, Fail, Blocked, bugs, screenshots, evidence, execution results, or Issue links.

When sources conflict, retain the official expectation, label ambiguity or contradiction, and verify only through observable black-box execution.
