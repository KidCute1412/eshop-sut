# Reporting and Evidence

## Evidence Required Per Scenario

- Raw `.jtl` log.
- HTML report folder.
- Screenshot of JMeter/k6 and backend resource monitor in the same frame.
- Notes about start time, end time, VUs, ramp-up, duration/loops, and database reset.

## Hardware Evidence

Capture a real screenshot or exported report from one of:

- dxdiag.
- systeminfo.
- screenfetch/neofetch.
- Task Manager Performance tab plus hostname evidence.

The hostname must match previous homework deployments or be explained.

## README Summary

Include:

- Scenarios run.
- Endpoint groups covered.
- Endurance threshold with numbers.
- Number of bugs/performance issues.
- Demo video link.
- Self-assessment table.

## Final Report Warnings

Do not say "Passed" or give p95/RPS values unless those values exist in raw logs. Use "Pending real
execution" when a tool is unavailable.
