# BUG-FR09-003: API vẫn cho áp dụng coupon khi không có user/token hợp lệ

## Mô tả
API apply coupon vẫn chấp nhận yêu cầu và áp dụng coupon thành công ngay cả khi không có token người dùng hợp lệ (chưa đăng nhập).

## Tiền điều kiện
- SUT đang chạy
- Coupon SAVE10 tồn tại

## Các bước tái hiện
1. Gửi request POST /api/apply-coupon với code=SAVE10, total=500000, không gửi token/user_id
2. Quan sát phản hồi từ API

## Kết quả mong đợi
Hệ thống phải từ chối áp dụng coupon khi người dùng chưa đăng nhập (không có JWT token hợp lệ), trả về lỗi 401 hoặc 403.

## Kết quả thực tế
API vẫn áp dụng coupon thành công với `{"success":true,"coupon_id":1,"discount_amount":-4500000,"final_amount":5000000}` dù user_id = null / không có token.
