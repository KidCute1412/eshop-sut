# BUG-FR09-001: Coupon bị từ chối khi tổng tiền bằng đúng min_order_amount

## Mô tả
Coupon bị từ chối khi tổng tiền đơn hàng bằng đúng min_order_amount, mặc dù điều kiện yêu cầu là total >= min_order_amount.

## Tiền điều kiện
- SUT đang chạy
- Coupon SAVE10 có min_order_amount = 300000
- Coupon BIGBUY có min_order_amount = 500000

## Các bước tái hiện
1. Gửi request apply coupon SAVE10 với total = 300000 (bằng min_order_amount)
2. Quan sát phản hồi lỗi từ API
3. Lặp lại với coupon BIGBUY và total = 500000

## Kết quả mong đợi
Hệ thống chấp nhận coupon khi total = min_order_amount vì điều kiện là total >= min_order_amount.

## Kết quả thực tế
API trả lỗi "Đơn hàng chưa đủ giá trị tối thiểu 300.000 ₫ để áp dụng mã này" khi total bằng đúng min_order_amount. Backend dùng `>` thay vì `>=` trong kiểm tra.
