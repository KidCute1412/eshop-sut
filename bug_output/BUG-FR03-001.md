# BUG-FR03-001: Backend chấp nhận mật khẩu yếu khi đặt lại mật khẩu

| Mục | Thông tin |

| Test case liên quan | FR03-DT-06, FR03-BVA-07 |
| Mức độ nghiêm trọng | High |
| Trạng thái | Open |

## Mô tả
Backend không kiểm tra độ mạnh của mật khẩu khi đặt lại mật khẩu, chấp nhận cả mật khẩu yếu như "weak" hoặc mật khẩu có 7 ký tự.

## Tiền điều kiện
- SUT đang chạy
- Đã tạo OTP hợp lệ cho email đã đăng ký

## Các bước tái hiện
1. Gửi request POST /api/reset-password với email đã đăng ký, OTP hợp lệ và newPassword = "weak"
2. Quan sát phản hồi từ API
3. Lặp lại với newPassword = "Abc1!xy" (7 ký tự)

## Kết quả mong đợi
Hệ thống từ chối mật khẩu yếu (dưới 8 ký tự, thiếu chữ hoa, chữ thường, chữ số hoặc ký tự đặc biệt) theo quy tắc FR-01.

## Kết quả thực tế
API trả `{"message":"Password reset successfully"}` — backend chấp nhận mật khẩu yếu `weak` và mật khẩu 7 ký tự `Abc1!xy`.
