# BUG-FR13-002: User không phải Admin vẫn truy cập được tài nguyên admin

## Mô tả
User thường (không phải Admin) vẫn có thể truy cập API và tài nguyên admin thành công, hệ thống không kiểm tra quyền truy cập.

## Tiền điều kiện
- Có token của user thường (role != admin)

## Các bước tái hiện
1. Đăng nhập với tài khoản user thường (không phải Admin)
2. Gửi request đến API admin resource
3. Quan sát request thành công thay vì bị từ chối

## Kết quả mong đợi
Hệ thống phải từ chối truy cập với mã lỗi 401 hoặc 403 khi user thường cố gắng truy cập tài nguyên admin.

## Kết quả thực tế
Request của user không phải Admin vẫn được chấp nhận cho tài nguyên admin.

## Minh chứng
- Quan sát phản hồi API bằng token user thường
