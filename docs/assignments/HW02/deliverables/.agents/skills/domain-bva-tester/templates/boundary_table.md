### Boundary Value Analysis (BVA) Table

Use the following format to document BVA boundary values:

| Variable | Boundary Condition | In-Point | On-Point | Off-Point | ID |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Variable Name** | e.g., Value must be $\ge 1$ | e.g., 5 | e.g., 1 | e.g., 0 | BVA-BND-01 |
