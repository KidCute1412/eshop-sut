### Equivalence Partitioning (EP) Table

Use the following format to document equivalence partitioning for variables:

| Variable / Condition | Valid Equivalence Classes | Invalid Equivalence Classes |
| :--- | :--- | :--- |
| **Variable Name**<br>*(Type, e.g., Integer)* | **EP-VAL-01**: Description (value range)<br>**EP-VAL-02**: Description (value range) | **EP-INV-01**: Description (value range)<br>**EP-INV-02**: Description (value range) |
