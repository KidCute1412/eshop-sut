# HW02 - Domain Testing Requirements Checklist

This checklist is based on the official assignment specifications in [2026.HW02.Domain Testing_En.pdf](file:///D:/HCMUS/Third%20Year/Software%20Testing/eshop-sut/docs/assignments/HW02/2026.HW02.Domain%20Testing_En.pdf).

## 📋 Checklist of Tasks to Do
For each of your **4 selected features** (one feature chosen from each of the pools: **Pool A**, **Pool B**, **Pool C**, and **Pool D - Mobile App**):
- [ ] **Domain Testing**: Apply the technique using AI tools, design a comprehensive set of test cases, and write a detailed, step-by-step application explanation.
- [ ] **Boundary Value Analysis (BVA)**: Apply BVA using AI, design a comprehensive set of test cases, and write a detailed, step-by-step application explanation.
- [ ] **AI Gap Analysis**: Document any test cases or bugs missed by the AI, explaining *why* they were missed.
- [ ] **Bug Reporting**: Report all discovered bugs with screenshots in the Markdown report and open them as issues on your group's GitHub Issues page.
- [ ] **Agent Skill**: Build and document Agent Skills that automate domain testing and boundary value analysis techniques.
- [ ] **Git Commits**: Create a Git commit for each step of the testing procedure for each feature.

---

## 📦 Submission Deliverables
You must submit a single `.zip` file on Moodle.
* **Filename Format**: `<StudentID>_HW02_AI_DomainTesting_<SelfAssessedGrade>.zip`
  * *Example*: `25127001_HW02_AI_DomainTesting_090.zip`
  * `<SelfAssessedGrade>` must be a 3-digit number in the range `[000, 100]`.

**Required contents of the `.zip` archive:**
1. **Main Report (`Markdown` + `PDF`)**: Includes the Domain Testing and Boundary Value Analysis reports.
2. **Bug Report**: Complete reports with bug screenshots attached to the GitHub Issues page.
3. **AI Critique & AI Audit Report (`Markdown` + `PDF`)**:
   - **Critique (200–300 words)**: Critiquing where the AI was wrong/biased/incomplete, why it failed, and lessons learned.
   - **Audit Report**: Documenting AI tool names, date/time, prompts, and outputs (mandatory if AI was used; otherwise, explicitly declare *"I do not use any AI help in this exercise."*).
4. **Git Commit Log (`.txt` format)**.
5. **README.md**: Must contain:
   - Self-assessment table using the assignment's grading template.
   - Test summary report (number of features, test cases designed/executed/passed/failed/pending, and bug count).
   - Demo video links (YouTube links showing end-to-end execution of your built Agent Skills).
6. **Agent Skills**: The code/configurations for the skills built during the task.
