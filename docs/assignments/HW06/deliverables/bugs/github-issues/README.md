# GitHub Issue copy-paste pack

Create one GitHub Issue for each `BUG-HW06-01.md` through `BUG-HW06-06.md`.
Copy the full content of one file into a new issue, submit it, then:

1. Copy its browser URL into `../bug-report.md`.
2. Capture the real issue page and save it as `../screenshots/bug_01.png` through `bug_06.png`.

Do not replace these issue files with screenshots; they are the reusable text source.
