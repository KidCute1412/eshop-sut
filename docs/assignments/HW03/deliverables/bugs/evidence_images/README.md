# Runtime Defect Evidence

This directory contains 15 authentic Google Chrome captures from the final desktop HW03 execution on 2 August 2026. Only failed checklist items have evidence images. Each PNG is referenced by its checklist row and verified defect record. Mobile defect evidence remains in the canonical `cross_platform/mobile_real_device/` directory and is referenced without duplication.

The screenshots contain no fabricated browser frame, timestamp, or GitHub content. Environment and execution metadata are recorded in the checklist and defect report. All 15 desktop defects were reproduced in two clean Google Chrome runs.
