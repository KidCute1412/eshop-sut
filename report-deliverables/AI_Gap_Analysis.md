FR-05: Product listing and search

The Equivalence classes generated by the agent has many flaws. The main reasoning for this is due to FR-05 being not applicable for boundary value analysis, as well as many sub-requirements under FR-05 to not require a partition. The list of equivalence classes (ECs) generated have been viewed, modified and adjusted by the tester, specifically:
- Removed ECs where the "partition" are simple UI checks.
- Corrected the ECs to indicate no usage of boundary value analysis is applicable here.
- Readjusted input values to actually match products within the database.
- Added an additional EC for Unicode search terms (like "Bàn phím").
- Added ECs for outputs (matching, empty, full products) as they were missing.

Similarly, the test cases are readjusted to match the correct equivalence classes while one more test is create for the new EC. Full details can be found within the traceability matrix and test table. 4 test cases are also merged into 2: loading screen observer and an invalid search, empty message and a blank search.

Minor error, when displaying HTML elements as text, "&amp;lt;" is used to replace "<" in HTML brackets, otherwise they will be not appear.
