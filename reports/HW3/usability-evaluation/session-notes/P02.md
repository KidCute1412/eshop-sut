## Probe Question Answers

- Clarity: The participant stated that the password requirements were confusing because the interface indicated that a special character was required, but common special characters such as **@** and **!** were rejected. After registration, they were also confused because the Login page still displayed the **"Register"** heading, and the interface mixed Vietnamese text with the English **"Sign In"** label.
- Error recovery: The participant reported trying several different passwords before finding one that was accepted. During the profile update, they only intended to change their shipping address, but the system still required a valid phone number and displayed a validation error even though the phone number field had been left empty. The participant was unsure how to proceed because the error message did not explain why the field was required.
- Speed: The participant felt that navigating through the registration and login flow was relatively quick. However, the repeated password attempts and unexpected phone number validation increased the overall completion time.
- Trust: The participant reported low confidence in the system because of inconsistent labels and unexpected validation behavior. They were uncertain whether the profile update would ever succeed when an unrelated field prevented the changes from being saved.
- Additional: The participant suggested using consistent language throughout the interface and providing clearer validation messages, especially when a required field blocks an update.

## Facilitator Summary

- Password validation rules were inconsistent with the guidance shown on the Register page, causing multiple failed attempts.
- The Login page incorrectly displayed the **"Register"** heading after successful registration, and the mixed-language interface (Vietnamese with the English **"Sign In"** label) caused additional confusion.
- Updating only the shipping address still triggered phone number validation, preventing the participant from saving unrelated changes.
- Validation behavior and inconsistent interface labels reduced the participant's confidence in the system.
