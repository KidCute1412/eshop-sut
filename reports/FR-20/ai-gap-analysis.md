## Lessons Learned

- For mobile features, API login success and mobile login success must be modeled and tested separately.
- UI conformance rules need both valid and invalid partitions, especially for required markers, masking, error placement, and post-login state.
- BVA for lockout is stateful; every boundary needs a clean account or controlled reset strategy.
- A temporary runtime blocker should be revisited when new evidence appears; stale blockers should not remain in the gap summary.
- AI gap analysis must distinguish an AI-missed case from a human improvement and from a runtime bug discovered by later execution.
