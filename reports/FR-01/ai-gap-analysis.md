## Classification of Findings

### AI-missed test cases

Exactly eight cases were genuinely absent from the initial suite and added by the human: FR01-DT-022 through FR01-DT-029. They cover UI/API invalid password length, API malformed/duplicate email, and API password character-class violations.

### Human improvements to existing tests

No initial case was removed or reclassified. All 29 retained cases were rewritten or corrected in at least one design field. These are quality improvements to existing tests, not “missed test cases.”

### Runtime bugs exposed by AI-generated tests

BUG-FR01-001 through BUG-FR01-004 were exposed by tests already present in the initial AI suite. The minimum-length portion of BUG-FR01-007 was also exposed by AI-generated FR01-BVA-005. These bugs were runtime discoveries, not bugs the AI had previously missed.

### Runtime bugs enabled by human-added tests

BUG-FR01-005 and BUG-FR01-006 were exposed by human-added FR01-DT-023 and DT-024. The expanded character-class and invalid-partition coverage within BUG-FR01-007 came from human-added DT-025 through DT-029.
